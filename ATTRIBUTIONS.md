# Attributions: mbarcade.online

mbarcade.online is a single HTML file. It loads no external scripts, fonts, images, audio or stylesheets (the page's Content-Security-Policy blocks them), so there are no third-party libraries to credit. What is in the file:

## Code and design
- All HTML, CSS and JavaScript is original to this project, including the "Utility" theme shared with the other mb apps.
- Fonts: none bundled. The page uses each device's own system font (Segoe UI, San Francisco, Roboto, etc.).

## Icons and logo
- The logo, favicon and iPhone home-screen icon (a die face on a felt-teal badge) are original artwork made for this site.
- The small interface icons (speaker on/off, chevron down, chevron up) are simple line shapes drawn inline as SVG. Their style matches the open-source Lucide / Feather icon sets, and the speaker and chevron paths may have been derived from them. I can't confirm that either way (about 70% likely). If you want to be safe, credit them:
  - Lucide, https://lucide.dev, ISC License, copyright the Lucide Contributors (includes portions from Feather, MIT License, copyright Cole Bemis).
- Suit symbols (♥ ♦ ♠ ♣) are standard Unicode characters drawn by the device's font. Status messages use a few Unicode emoji, which each device draws in its own emoji font.

## Sound
- All sounds are generated live in the browser with the Web Audio API (simple tones and noise). No audio files are used.

## Game content
- **8-Ball:** the 20 answers are the traditional fortune-ball phrases. "Magic 8 Ball" is a trademark of Mattel. This site is not affiliated with or endorsed by Mattel and does not use that name.
- **Red/Black, Roulette, Cee-Lo:** traditional games with no owner. The code for each is original.
- **Random numbers:** from the browser's built-in `crypto.getRandomValues`.
